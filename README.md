# rifanft-blockchain
Rifa con boletos NFT (ERC-721) y token RIFA (ERC-20) para el curso de Blockchain
## Contratos
- RifaToken: oferta fija de 10 000 000 RIFA, con distribución y quema.
- RifaNFT: venta de boletos, sorteo, reembolso, gobernanza y pausa.

## Cómo probarlo
1. Abrir remix.ethereum.org y pegar RifaNFT.sol.
2. Compilar con Solidity 0.8.34 (Weno, es lo q yo usé)
3. Desplegar primero RifaToken y luego RifaNFT.
